# Little Garage 小车库

A small, calm K1 learning app (English, Maths, 华文) with a car theme, for iPad Safari in landscape.
Plain HTML/CSS/JS, no build step, works offline. Voice: generated TTS clips (no personal recordings).

Unlisted on purpose: `noindex, nofollow` meta tag and `robots.txt` (`Disallow: /`). No analytics, no accounts, no network
calls beyond this site and the picture book it links to. Progress and stickers stay on the device (localStorage) only.
